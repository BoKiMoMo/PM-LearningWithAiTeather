# 📘 DAY 12 – 使用者測試規劃與分析 + C++
(DAY 12 – User Testing Planning & Analysis + C++ Practice)

---

## 🎯 主題說明｜Topic Introduction

**中文：**
使用者測試（User Testing）是檢驗產品設計與功能是否符合用戶需求的重要環節。本日課程將介紹如何規劃使用者測試、分析結果，並搭配 C++ 的練習，加深邏輯思維與資料處理能力。

**English:**
User testing is a crucial step to validate whether the product design and features meet user needs. Today’s lesson will cover planning user tests, analyzing the results, and practicing C++ to strengthen logical thinking and data processing skills.

---

## 🧠 概念導入｜Concept Analogy

**中文：**
使用者測試就像試菜。廚師必須邀請客人試吃，觀察他們的反應，並根據反饋調整味道與食材比例。

**English:**
User testing is like tasting a dish before serving. The chef invites guests to try it, observes their reactions, and adjusts flavors or ingredients based on feedback.

---

## 🔍 核心步驟｜Core Steps

1. **確立測試目標**  
   - 中文：明確定義要驗證的功能或假設。  
   - English: Clearly define the features or hypotheses to validate.

2. **招募測試對象**  
   - 中文：選擇符合目標用戶特徵的參與者。  
   - English: Recruit participants that match the target user profile.

3. **設計測試任務**  
   - 中文：模擬真實使用情境，設定具體操作任務。  
   - English: Simulate real scenarios with specific tasks.

4. **收集與記錄數據**  
   - 中文：記錄操作時間、成功率、錯誤率及用戶感受。  
   - English: Record task time, success rate, error rate, and user feedback.

5. **分析結果與優化**  
   - 中文：整理數據與意見，提出改進方案。  
   - English: Summarize data and feedback to suggest improvements.
