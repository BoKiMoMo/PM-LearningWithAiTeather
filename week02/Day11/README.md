# 📘 DAY 11 – Figma 原型製作（互動功能）
(DAY 11 – Figma Prototype Creation with Interactive Features)

---

## 🎯 主題說明｜Topic Introduction

**中文：**
Figma 是一款雲端協作設計工具，廣泛應用於產品設計、UI/UX 原型製作。本日課程將介紹如何在 Figma 中建立互動原型，讓團隊成員與用戶能更直觀地理解產品設計概念。

**English:**
Figma is a cloud-based collaborative design tool widely used for product design and UI/UX prototyping. Today’s lesson will cover creating interactive prototypes in Figma, enabling teams and users to better visualize and understand design concepts.

---

## 🧠 概念導入｜Concept Analogy

**中文：**
可以將 Figma 的互動原型想像成房屋樣品屋。雖然不是實際房子，但可以讓人走一圈，體驗動線與空間配置。

**English:**
Think of an interactive prototype in Figma like a show house. It’s not the actual house, but it allows people to walk through and experience the layout and flow.

---

## 🔍 核心步驟｜Core Steps

1. **建立畫框（Frame）**  
   - 中文：定義頁面與裝置尺寸。  
   - English: Define page and device dimensions.

2. **設計 UI 元素**  
   - 中文：添加按鈕、文字框、圖片等元素。  
   - English: Add buttons, text fields, images, etc.

3. **連接互動**  
   - 中文：使用 Prototype 模式建立頁面之間的連結與過渡動畫。  
   - English: Use Prototype mode to link pages and add transition animations.

4. **預覽與測試**  
   - 中文：透過 Presentation 模式檢視互動效果。  
   - English: Use Presentation mode to preview and test interactions.

---

## ✍ 實作任務｜Practice

1. **中文：** 建立一個三頁的 APP 原型（首頁、功能頁、設定頁），並加入至少 3 個互動連結。  
2. **English:** Create a 3-page app prototype (home, feature, settings) and add at least 3 interactive links.

---

## 🔊 技術英文句型｜Tech English Practice

- "Clicking this button will navigate to the settings page."
- "This animation creates a smoother user experience."
- "The prototype simulates the core user flow."

---

## 📖 詞彙對照表｜Glossary

| 中文 | English | 說明 |
| --- | --- | --- |
| 畫框 | Frame | Figma 中定義設計頁面的容器 |
| 原型模式 | Prototype Mode | 在 Figma 中建立互動連結的功能 |
| 過渡動畫 | Transition Animation | 頁面切換時的動畫效果 |
| 預覽模式 | Presentation Mode | 用於測試與展示設計的模式 |
| 互動連結 | Interactive Link | 讓元素能導向其他頁面的連結設定 |
